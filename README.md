# Automated Flood Barrier System

### Project Overview
The Automated Flood Barrier System is a responsive infrastructure prototype built to prevent structural water damage using automated mechanical controls. Operating on an Arduino microcontroller platform, the system relies on an ultrasonic sensor to monitor the approach distance of rising floodwaters and an analog water sensor to track ground-level moisture accumulation. As sensor inputs are evaluated, the system outputs live metrics to a 16x2 I2C LCD screen, changes color codes on an RGB LED indicator, and operates a high-torque servo motor to pivot a physical barrier gate into defensive positions depending on environmental risks.

### Circuit Wiring and Pin Map
To assemble the circuit safely, all electronic components must share a unified electrical ground with the Arduino board. The HC-SR04 ultrasonic sensor uses digital pin 9 for its trigger function to send ultrasonic pulses and digital pin 10 for its echo function to read returned signals. The analog water level sensor wires directly into analog pin A0 to capture continuous moisture variations. For alerts and indicators, an active buzzer links to digital pin 7, while the red and green legs of a common-cathode RGB LED connect to digital pins 3 and 4, respectively. The physical barrier gate is attached to a servo motor driven by PWM digital pin 6. Real-time textual data is transmitted to the LiquidCrystal I2C LCD screen via the dedicated hardware I2C lines, which are pins A4 for serial data and A5 for the serial clock on standard boards.

### System Behavior and Conditions
The control loop updates every 500 milliseconds to sort environmental data into three operational states. Under a normal state, defined by an approach distance greater than 5 centimeters, the LCD reads a status of normal, the green LED illuminates, and the servo motor holds the gate at a ready position of 45 degrees. If the approach distance drops into a warning window between 2 and 5 centimeters, the state switches to a warning mode, shifting the RGB LED to yellow by turning on both the red and green pins simultaneously while the servo holds its ready position. When a critical flood state occurs, triggered by an approach distance of 2 centimeters or less or by the water sensor reading a moisture value exceeding a threshold of 500, the system responds immediately. It prints a flood warning on the LCD, shifts the RGB LED to a solid red color, triggers a rapid pulsing audio alarm through the buzzer, and rotates the servo motor to 130 degrees to deploy the flood barrier gate completely.

### Step-by-Step Run Guide
To run the project, begin by setting up your software environment in the Arduino IDE and installing the required LiquidCrystal I2C library by Frank de Brabander alongside the built-in Servo library. With the software ready, disconnect power from your hardware components and wire the pins exactly as described in the circuit layout section. Next, create a new project file named Automated_Flood_Barrier inside your local workspace directory, copy the repository code, and paste it into the IDE editor window. Connect your Arduino microcontroller to your machine using a compatible USB cable, navigate to the tools menu to match your specific board model, and choose the active serial COM port assigned to the device. Click the verify button to compile the syntax, and if zero errors are found, click the upload button to flash the compiled binary file directly into the board's internal memory. Finally, open the serial monitor at a 9600 baud rate to view live feedback, and test the mechanism by placing an object close to the ultrasonic sensor grid or submerging the water probe to verify that the barrier deploys, the red LED lights up, and the buzzer alarm activates correctly.
